# Blinkit-Premium-Sales-Dashboard.
# 📌 Project Overview
This project is an interactive Power BI dashboard built to analyze Blinkit's grocery sales data. Instead of a standard default layout, I designed a custom, premium UI using a dark navy canvas with vibrant gold KPI cards and borders to create an app-like experience.

## 🛠️ Tools Used
* **Power BI Desktop** (Data Visualization, Custom UI Design)
* **Power Query** (Data Transformation)

## 📊 Dashboard Features
* **Premium UI:** Custom shapes, gold borders, and a dark navy background.
* **KPI Cards:** Total Sales, Average Rating, Total Items, and Average Item Weight.
* **Visualizations:** 
  - Top 5 Items by Sales (Bar Chart)
  - Sales Distribution (Top 5 Donut Chart)
  - Weight vs. Sales (Scatter Chart)
* **Interactive Slicer:** Filter the entire dashboard by Rating.
